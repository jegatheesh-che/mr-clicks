# Typography Pairing — Reference

Color sets the emotional register; type has to argue the same case or the design reads as confused. Use this after picking a palette from `palette-library.md`.

## Core pairing logic

**Pair by contrast of role, not similarity of style.** The classic reliable structure is one **display face** with real personality (used large, sparingly — headlines, hero text) + one **quiet body face** (used small, extensively — paragraphs, UI copy) + optionally one **mono/utility face** (labels, numbers, code, eyebrows). Two loud display faces fighting each other is the most common amateur mistake; two timid body faces paired together is the second most common (nothing gets the personality job done).

**Match the era and formality, not just the mood.** A geometric sans display face paired with an old-style serif body face can work, but only if the brief's tone spans both worlds (e.g., "heritage brand, modern relaunch"). If the pairing has no story to tell, it reads as arbitrary rather than intentional — be able to say in one sentence *why* these two faces are together.

**Let value structure guide weight.** High-contrast palettes (Cyber Noir, Neo-Brutalist) usually want a display face with real weight range (thin-to-black) so headlines can be genuinely heavy against a dark or stark background. Restrained palettes (Editorial Mono, Scandinavian Minimal) often want the opposite — a display face that gets its personality from proportion and detail (unusual x-height, distinctive italics, a characterful serif) rather than sheer weight, since heaviness would fight the restraint.

**Type scale should have real jumps, not timid increments.** A common tell of an unrefined design is a type scale that goes 16 / 18 / 20 / 24px — too even, no hierarchy. Prefer something closer to a 1.333–1.5 ratio scale (e.g., 16 / 21 / 28 / 38 / 51px) so headline vs. body is unmistakable at a glance.

## Pairing recipes by palette mood

Font families below are given as *categories with representative examples* (many are on Google Fonts or similar open sources) — swap for licensed equivalents as needed, the important thing is the structural pairing logic, not the exact named typeface.

**Editorial Mono** → a high-contrast serif with strong verticals for display (e.g., Freight Display, Canela, or GT Sectra–style) + a clean humanist sans for body (e.g., Inter, Söhne, GT America). The serif carries all the personality; the sans stays invisible.

**Warm Luxury** → a refined, slightly condensed serif or high-contrast didone for display (e.g., Canela, Ogg, Reckless) + a warm-toned humanist sans or serif for body (e.g., Tiempos Text, Source Serif). Avoid geometric sans display faces here — they read tech, not luxury.

**Cyber Noir** → a technical, geometric or grotesk sans with a distinct personality for display (e.g., Neue Machina, Space Grotesk, General Sans) + a clean grotesk for body (e.g., Inter, Suisse Int'l) + a monospace for labels/data (e.g., JetBrains Mono, IBM Plex Mono). The mono face is doing real work here, not decoration — use it for anything numeric or systemic.

**Neo-Brutalist Acid** → an oversized, unapologetic grotesk or even a slightly ugly-on-purpose sans for display (e.g., Archivo Black, Public Sans Bold, Helvetica Now Black) + a plain, almost aggressively neutral sans for body (e.g., Arial-adjacent, Helvetica). The "flaw" is the point — overly polished type undercuts the brutalist thesis.

**Soft Clinical** → a rounded or softened grotesk for display (e.g., General Sans, Switzer) + the same family or a close cousin for body, keeping weight contrast subtle. Avoid serifs entirely here — they read "traditional," working against the clinical-modern thesis.

**Earthy Organic** → a humanist serif with warmth for display (e.g., Lora, Fraunces, Tiempos) + a warm sans for body (e.g., Nunito Sans, Karla). Fraunces in particular has a soft, almost hand-drawn quality that pairs well with desaturated earth palettes.

**Scandinavian Minimal** → this is the formula most dependent on type doing the personality work since color deliberately isn't. Pick a display face with one distinctive structural quirk (an unusual italic, an ink-trap detail, a tall x-height) — e.g., Söhne, Founders Grotesk — and let it be the entire signature. Body face should be nearly identical in tone (often the same family, different weight) to keep the restraint intact.

**Retro-Futurism** → a period-specific display face — rounded geometric sans evoking 70s (e.g., Cooper-adjacent, Recoleta) or angular/chrome-evoking display for 80s (e.g., a squared display face) + a period-appropriate but readable body sans. The type should date-stamp the design as intentionally as the color duo does.

**Maximalist Gradient** → display face can be expressive and large (e.g., a variable/wide-weight-range sans like Cabinet Grotesk) but body face should be maximally neutral and small (e.g., Inter at a conservative size) — the anchor-neutral logic from the palette applies to type too: color and shape get to be loud, but the actual reading experience needs one calm element.

**Dark Glass (Glassmorphism)** → a clean, slightly futuristic grotesk for display (e.g., Aeonik, General Sans) + the same or a close relative for body. Avoid anything with heavy serifs or ornament — the glass/blur aesthetic wants type that feels equally translucent and modern.

**High-Contrast Monochrome** → this formula lives or dies on the display face alone, since color isn't available to help. Pick something with genuine, unusual character — a high-contrast didone (e.g., Canela, GT Sectra) or a very confident grotesk (e.g., Neue Haas Grotesk Display) — and give it real size (don't be shy, go larger than feels comfortable).

**Bio-Luminescent (Nature-Tech)** → an organic-but-technical sans for display (e.g., a rounded geometric like Cabinet Grotesk or General Sans) + a clean grotesk for body + consider a mono for data/stats to reinforce the "tech" half of the nature-tech duality.

## Fast checklist before finalizing type

- Does the display face have a clear reason for being paired with this body face (shared era, deliberate contrast, or both from a coherent type family)?
- Is there a real size/weight jump between heading and body levels (not a timid 2-4px difference)?
- Line length for body text: aim for 50-75 characters per line — wider reads as unedited, narrower feels choppy.
- If using a mono/utility face, is it actually reinforcing something (data, code, labels, systemic content) rather than added for decoration?
