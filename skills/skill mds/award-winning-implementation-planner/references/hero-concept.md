# Hero Concept

Every site that wins an Awwwards "Site of the Day" is built around ONE idea — not a list of sections and features. Before planning any layout or animation, write this idea down in 1-2 sentences. Everything else in the plan gets checked against it.

## The three usual sources of a hero concept

**1. A visual metaphor.** The site's structure or motion literally represents the subject.
- Example: a coffee roastery site where scroll progress visually "roasts" a bean from green to dark as you move down the page.
- Example: a photographer whose site scrolls like flipping through a physical contact sheet / lightbox.

**2. A single signature interaction.** One moment (usually the hero) that's unusual enough to be the thing people screenshot or talk about.
- Example: a magnetic cursor that behaves like it has weight, used ONLY on the hero CTA, nowhere else — so it stays special.
- Example: a hero image that responds to scroll with a mask reveal shaped like the brand's icon.

**3. A narrative through-line.** The scroll journey tells a story with a beginning, middle, end — sections aren't just stacked, they escalate.
- Example: a case-study site structured as problem → process → transformation → result, each with escalating visual intensity.

## How to derive it for a given brief

1. Ask: what's the ONE thing about this subject that's visually or emotionally distinct? (For a photography brief: is it about light? motion? stillness? a specific place or culture?)
2. Pick the metaphor/interaction/narrative that expresses that thing with the LEAST amount of added complexity — the best hero concepts are simple enough to say in one sentence and hard enough that a template couldn't have thought of it.
3. Write it as: **"Hero concept: [1-2 sentence idea]."** e.g. *"Hero concept: the site scrolls like golden hour fading to blue hour — the color grade of every section shifts gradually as you scroll, mirroring a single day's light."*

## The cut test
For every section or animation moment proposed later in the plan, ask: **"does this serve the hero concept, or is it just decoration?"** If it's just decoration, cut it or fold it into something that does serve the concept. This is the single biggest difference between a site that feels curated and one that feels like a features list.
