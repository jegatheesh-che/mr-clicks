# Knowledge Framework

Reference theory to cite precisely, not decoratively. Cite a principle only when it's actually doing explanatory work.

**Visual Hierarchy** — order of attention controlled by size, contrast, color, isolation (whitespace), and position. A layout has exactly one true "first" element; if two elements are equally weighted, hierarchy has failed.

**Gestalt Principles** — proximity (near = related), similarity (same style = same category), continuity (the eye follows implied lines), closure (the mind completes incomplete shapes), figure-ground (what reads as subject vs. background).

**Hick's Law** — decision time increases with the number and complexity of choices. Relevant to nav item counts, CTA counts, form field counts.

**Miller's Law** — working memory holds roughly 7±2 chunks; relevant to how much a hero asks a user to process at once (headline + subhead + CTA + trust signal is near the ceiling before it starts feeling busy).

**F-Pattern / Z-Pattern** — F-pattern for text-heavy/scanning contexts (left-aligned copy blocks), Z-pattern for sparse, visual-led layouts (top-left → top-right → bottom-left → bottom-right, typically ending at the CTA).

**Color Theory** — hue/saturation/value relationships; complementary and split-complementary schemes for contrast; warm-forward/cool-recessive spatial effects; the practical distinction between a color *palette* (hues chosen) and a color *system* (roles assigned: dominant, neutral, accent, semantic).

**Typography Systems** — modular scale (a consistent size ratio, e.g. 1.25x, across heading levels), pairing logic (contrast in category — serif/sans, geometric/humanist — rather than similarity), optical vs. mathematical alignment.

**Spacing Systems** — base-unit scales (commonly 4px or 8px) multiplied up; consistent spacing reads as intentional even when the viewer can't articulate why.

**Attention Economics** — attention is the scarce resource being spent; every element competing for it has a cost, so competent design is as much about subtraction as addition.

**Emotional / Semiotic Design** — color temperature, type weight, image tone, and motion pace all carry connotations (heavy dark serif + slow motion ≈ gravitas/luxury; bright rounded sans + fast motion ≈ playful/consumer). Congruence between these signals and the brand's actual positioning is a key quality marker.

**Conversion Psychology** — specificity beats vagueness in CTA copy; proximity of trust signals to the decision point reduces perceived risk; too many competing CTAs cause decision paralysis (ties back to Hick's Law).

**Luxury / Premium Design Cues** — restraint (fewer, larger, more deliberate elements), generous whitespace, muted or highly controlled palettes, high-quality/art-directed imagery over stock, subtlety in motion over flashiness.

**Motion Design Principles** — staged reveal (elements enter in hierarchy order, not simultaneously), easing that matches brand tone (snappy/mechanical vs. slow/organic), restraint (motion should clarify hierarchy, not perform).
