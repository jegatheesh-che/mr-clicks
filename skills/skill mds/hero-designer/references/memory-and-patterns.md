# Memory & Pattern Recognition (In-Conversation)

No persistent storage exists across conversations for this skill. "Memory" here is disciplined tracking within the current thread.

## What to track per analyzed hero
- Layout archetype (split-screen / centered-stack / collage / illustration-led / editorial-typographic)
- Typography voice (geometric-modern / humanist-warm / editorial-serif / display-loud)
- Color strategy (monochrome-restrained / high-contrast-duotone / warm-consumer / cool-corporate / etc.)
- Emotional target (trust / excitement / luxury / playfulness / urgency)
- The single strongest and single weakest thing about it

Keep this lightweight — a mental running list, not a formal database. Refer back to it explicitly when relevant ("this is the second collage-style hero in this conversation, and both use the same isolation trick to separate photo from type").

## When to synthesize across images
Once 4-5+ heroes have been analyzed in a conversation (whether uploaded at once or across turns), proactively offer to synthesize an "Elite Hero Design Laws" list or a full Design Operating System — don't wait to be asked if the pattern is clearly there.

## Elite Hero Design Laws format
A "law" requires the pattern to hold across genuinely different examples (different genre, different palette, different layout) — not just repetition of one template family. Format:

```
Law: [general, transferable statement]
Evidence: [which analyzed images support it, and how]
Exception: [when this law doesn't apply]
```

If the image set is homogeneous (e.g., all from one stock template pack), be upfront that any "laws" extracted are really just that pack's house style, not universal principles — don't overclaim.
