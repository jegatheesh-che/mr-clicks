# Analysis Engine — Stage-by-Stage

Run these in order for a full Single Screenshot Analysis. Each stage should produce a short, specific paragraph or a few bullets — not padding. Skip a stage only if it's genuinely not applicable (e.g., no imagery present).

### Stage 1 — First Impression
Simulate the sub-3-second read. What lands first? What's the one-sentence takeaway a distracted user would walk away with? Note gut emotional reaction before analysis kicks in — this is data about the design's effectiveness, not a throwaway intro.

### Stage 2 — Emotional Impact
Name the target feeling (trust, excitement, calm, urgency, aspiration, playfulness) and identify the 2-3 specific visual levers producing it (color temperature, type weight, imagery tone, whitespace density, motion implied).

### Stage 3 — Visual Hierarchy
Rank the elements by which wins attention first, second, third. Name the specific mechanism for each (size, contrast, isolation via whitespace, color saturation, position on the F/Z path). Flag any hierarchy conflicts (two elements fighting for first place).

### Stage 4 — Layout Blueprint
Identify the underlying grid/column structure, the composition type (centered, split-screen, asymmetric, layered/collage), and how balance is achieved (symmetric weight vs. counterweighted asymmetry).

### Stage 5 — Typography System
Identify: typeface personality (geometric/humanist/serif/display), apparent type scale (how many size steps, and the likely ratio), weight contrast, and whether pairing (if multiple typefaces) is doing a specific job (voice vs. utility) or just decorative.

### Stage 6 — Spacing System
Assess whether spacing looks systematic (consistent scale — e.g. 8px-based) or ad hoc. Evaluate density: is it giving the content room to breathe relative to its ambition (premium brands are usually roomier), or cramped?

### Stage 7 — Color Strategy
Break down the palette into roles (dominant/neutral/accent), not just hues. Assess contrast for both legibility and hierarchy. Note if the palette is genre-appropriate and whether it's distinctive or generic-trendy.

### Stage 8 — Imagery Analysis
Identify the imagery type (photography/illustration/3D/abstract/none) and assess whether it's art-directed and specific vs. generic stock. If people are shown, note gaze direction and whether it's used to guide attention.

### Stage 9 — Motion Possibilities
Even from a static frame, describe what should animate, in what order, and why — tie every suggestion back to reinforcing hierarchy, not decoration. Note over-animation risk if the composition already has a lot going on.

### Stage 10 — Conversion Psychology
Evaluate the CTA: visibility, copy specificity ("Start free trial" vs "Submit"), and position in the reading flow. Note trust signals present or missing. Identify friction (too many competing actions, unclear value prop).

### Stage 11 — Premium Details
Look for the small, deliberate choices that separate competent from elite: micro-typography, a signature visual move, restraint where a lesser design would add more. If none are present, say so plainly.

### Stage 12 — Hidden Patterns
Surface structural choices that aren't obvious at a glance: an underlying grid the eye doesn't consciously register, a color relationship (e.g. exact complementary/split-complementary), a repeated proportion.

### Stage 13 — Reusable Design Rules
Convert 2-4 of the strongest observations from the stages above into Observation → Rule pairs (see SKILL.md Rule Extraction section for format).

### Stage 14 — Design System Extraction
Reverse-engineer implied design tokens: approximate type scale (e.g. 14/16/24/40/64), spacing scale, color roles with approximate hex families, corner-radius/border logic if visible.

### Stage 15 — Final Design Intelligence Report
Synthesize stages 1-14 into a short executive summary: what this hero is optimized for, how well it succeeds, the single biggest lever that would improve it, and the single biggest thing to steal from it.

## Multi-Image Pattern Recognition Mode

When 3+ images arrive together (very common — moodboard grids, swipe files, template packs):

1. Run a fast pass (Stages 1-3 only, 1-2 sentences each) per image.
2. Group images by structural archetype (split-screen, centered-stack, collage/layered, illustration-led, typographic/editorial), not by surface style or color.
3. For each archetype cluster, extract what's structurally shared — ignore color/typeface differences, focus on layout logic and hierarchy strategy.
4. Produce "Elite Hero Design Laws" — principles that hold across multiple genuinely different examples in the set, not just one image's idiosyncrasy. A pattern seen once is an observation; a pattern seen 3+ times across different styles is a law.
5. Be honest about set quality — stock template packs and marketplace mockups will mostly yield mid-tier, formulaic patterns (icon-plus-headline-plus-button banners, generic gradient blobs). That's a valid and useful finding — don't manufacture elite insight where the source material doesn't support it.
